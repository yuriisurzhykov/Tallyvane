# composer

The pill pinned to the bottom of the product's screens: "what's new?", then send — Tier 1.

## What needed doing

The product asks for words and does the rest, so the one control that must always be within reach is the place
to put them. It had been a bordered text area with a button under it, which read as a form to fill in rather
than a thing to talk to.

## What was actually done

One rounded field with a growing text area and a send button inside it. It is the only pill in the system, on
purpose: the one thing that is always there is the one thing shaped differently. Enter sends, Shift+Enter
starts a new line, and composition in progress (an IME) is never mistaken for Enter. Nothing is sent while the
field is empty or while a send is under way, and the send button says so by being disabled. The caller owns the
value and the sending; the composer owns only how it looks and which key does what.
