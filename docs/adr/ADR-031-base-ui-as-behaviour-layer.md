# ADR-031. Base UI как поведенческий слой примитивов

Отменяет упоминание shadcn в §12.5 версии 3.3.

## Решение

Механика сложных примитивов — меню, поповер, выдвижная панель, комбобокс,
табы, поля формы — берётся из **Base UI** (`@base-ui/react`). Оформление
целиком наше и приходит только из токенов. Ни одного класса и ни одного цвета
библиотека не привозит.

## Что было записано раньше и почему это не работает

§12.5 описывала `shared/ui` как «дизайн-систему на Tailwind и shadcn».
Упоминание единственное: в §12.7, где перечислен стек, shadcn не значится.
Решение, судя по всему, не принималось, а подразумевалось.

Исполненное буквально, оно ломает основание системы токенов. Компоненты shadcn
приезжают с классами `bg-background`, `text-muted-foreground`, `border-input`,
`ring-offset-background` и переменной `--radius`. Ни одного из этих имён у нас
не существует: пространства имён Tailwind очищены намеренно, а роли называются
`surface-primary`, `text-muted`, `radius-control`. Вставленный компонент не
выдаст ошибку — CSS разрешит несуществующую переменную в ничто, и на экране
появится элемент без цветов. Это тот самый молчаливый отказ, ради
предотвращения которого очищались пространства имён.

Переписывать классы каждого вставленного компонента можно, но тогда от shadcn
остаётся ровно то, что под ним, — а под ним поведенческая библиотека.

## Почему именно Base UI

Оформительский слой отделим от поведенческого, и нам нужен только второй.
Кандидатов на конец 2026 года четыре.

**Base UI** — стабильная 1.0 в декабре 2025, релизы помесячно, 1.7.0 в августе
2026. Делают инженеры, строившие Radix, вместе с авторами Floating UI и
командой MUI. Заявленная цель библиотеки — быть основанием для собственной
дизайн-системы, что дословно совпадает с нашей задачей. Один tree-shakable
пакет вместо россыпи. Есть `Combobox`, `Autocomplete`, `Drawer`, `Field`,
`Form`, `NumberField`, `ToggleGroup`, `Meter` — то есть ровно те компоненты,
которые нужны консоли.

**Radix** отвергнут не как плохой, а как менее подходящий. Он жив, поддерживается
WorkOS и остаётся отраслевым стандартом, но темп ниже, а незакрытые места —
комбобокс и мультиселект — приходятся ровно на выбор компании, контакта и
тегов, то есть на самые частые поля продукта. Показательно и то, что shadcn с
июля 2026 по умолчанию собирается на Base UI: следование §12.5 сегодня привело
бы туда же, только вместе с чужим слоем классов.

**React Aria** отвергнут с сожалением. У Adobe самая строгая реализация
WAI-ARIA, и у неё есть выбор даты, которого нам не хватает. Против — заметно
больший вес, API на хуках вместо композиции и множество провайдеров контекста
в дереве, которые плохо уживаются с другими библиотеками. Планка доступности у
нас высокая, но она проверяется тремя наборами в CI, а не выбирается
библиотекой; Base UI следует тем же WAI-ARIA-практикам.

**Своя реализация** отвергнута по объёму. За словом «меню» стоят возврат
фокуса на триггер, roving tabindex, Home и End, наборный поиск, переворот у
края экрана, портал в `body` и различение клика по триггеру от клика снаружи.
Каждый пункт — отдельный дефект, и почти все видны только с клавиатуры или
скринридером, то есть визуальными тестами не ловятся.

## Последствия

Инвариант токенов не затронут: Base UI выражает состояние через
`data-*`-атрибуты и не претендует на классы, поэтому правило «ни одно
имя класса не разрешается в примитив» остаётся в силе без исключений.

Портал требует `isolation: isolate` на корневом элементе приложения, чтобы
всплывающие слои гарантированно оказывались выше содержимого. Это соседствует с
нашей именованной лестницей наложения и должно быть согласовано с ней при
сборке оболочки, а не после.

Пакет `@base-ui/react` становится второй внешней зависимостью фронтенда после
движка токенов — и, в отличие от него, попадает в рантайм-бандл. ADR-026 уже
отменил утверждение, что внешних пакетов на фронтенде нет; это решение
расширяет исключение осознанно, а не тихо.

Тремя пробелами библиотека не закрывает: таблица с виртуализацией (TanStack
Table и Virtual, тоже headless), командная палитра (собирается из `Dialog` и
`Combobox`) и **выбор даты**, которого у Base UI нет вовсе. Последнее остаётся
открытым вопросом и зафиксировано в
`packages/frontend-shared/src/shared/ui/COMPONENTS.md` §13.
